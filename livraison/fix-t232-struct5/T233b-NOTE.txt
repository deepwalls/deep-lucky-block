2. FIX T233b : SELECTION 100 % BRUIT (zero chunk), DECISION < 1 s
----------------------------------------------------------------
On inverse la strategie de selection :
- Le centre est choisi ENTIEREMENT par sondes bruit
  (ChunkGenerator.getBaseHeight / WORLD_SURFACE_WG = API generateur,
  AUCUN chunk genere ni charge a cette etape).
- Les portes de terrain REEL (relief x0.6 max 10, colonnes d'eau,
  emprise exhaustive, clearance, conflits) restent le JUGE FINAL sur
  l'emprise generee ensuite. AUCUN critere d'acceptation desserre.
- Si le choix sec y echoue, il est blackliste (mecanisme F3 existant)
  et le choix sec suivant est propose instantanement ; l'abandon
  borne F2 (180 s) reste le garde-fou ultime en dernier recours.

Nouvelle methode : dryPickCenter(lvl, origin, checkR, fullCheckR,
structMax, p, minEdgeDist) dans Structures5Procedure.java :
- couronnes de pas ~une emprise, rayon 96 -> 768, emaillage tournant ;
- filtres secs par candidat : REJECTED_RUGGED_CENTERS, distance min
  joueur (meme regle que le scan historique), conflit StructureSites,
  hauteur centre <= 61 (ocean/riviere) ou >= 190 (paroi impropre) ;
- mesure span sec en 9 sondes (dryRuggedSpan T233 reutilisee) ;
- stoppe des qu'un candidat <= DRY_PICK_GOOD_SPAN (8 par defaut) ;
- sinon tant que le budget tient : BEST SO FAR, puis le budget
  DRY_PICK_BUDGET_MS (900 ms par defaut) EST UN PLAFOND DUR ;
- en cas d'echec quelconque (generateur exotique), retour null =
  le balayage historique T233 reprend le relais, rien n'est casse.
Injection : juste apres drainDeferred dans findFlat, avant le scan
historique ; bloc ~110 lignes, commente "T233b". Deux "Zone choisie"
distingues dans les logs par "(selection seche T233b : N ms, ...)".

Interrupteurs (valeurs par defaut = comportement visé, tout OFF = T233 pur) :
  -Ddlb.search.dryPick=0          desactive T233b completement
  -Ddlb.search.dryPickMs=900      budget temps decision (ms)
  -Ddlb.search.dryPickMaxR=768    rayon max du choix sec
  -Ddlb.search.dryPickGoodSpan=8  span sec juge "assez plat natif"

4. COMMENT REJOUER (serveur NeoForge 1.21.1, Java 21)
----------------------------------------------------------------
1) Sauvegarder votre instance actuelle.
2) Ecraser les fichiers de l'overlay complet (zip SRC-COMPLET T233b)
   aux memes chemins src/main/java/deepluckyblock/... dans votre
   projet mod, puis recompiler votre mod.
3) Tester en jeu : /dlbtest dragon (ou citadel/observatory/circus/ship)
   sur terrain hostile (montagne, ocean, foret) ; constater dans le
   chat l'apparition immediate de "Zone choisie a X, Z (selection
   seche T233b : N ms, ...)" avec N < 1000.
4) Faire varier simulation-distance / view-distance dans
   server.properties si serveur (ou options client) : la selection
   ne doit PAS bouger (independante des chunks charges).
5) Revenir au comportement T233 sans T233b si besoin :
   ajouter -Ddlb.search.dryPick=0 aux arguments JVM.
